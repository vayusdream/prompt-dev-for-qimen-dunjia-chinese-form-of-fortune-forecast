# 隔离并优先使用每位博主的知识体系

Creator Operations Tool 为每位博主建立完全隔离的 Creator Knowledge Base，并将该博主明确提供的 Creator Doctrine 作为内容生成的最高权威。我们不采用所有博主共享一套通用玄学知识的方案，因为奇门遁甲存在门派、术语和方法差异；公开网络资料可以帮助发现选题或补充背景，但不得自动覆盖博主口径，出现 Knowledge Conflict 时必须交由博主判断。

上传的原始 Knowledge Source 可以按其 Source Authority 作为参考资料检索，但系统从资料中提取的规则只能先成为 Proposed Knowledge Entry。只有经过博主确认或修订的 Confirmed Knowledge Entry 才能进入 Creator Doctrine；文档上传本身不构成对全部内容的权威确认。

生成结果中的关键专业主张必须在审核界面提供 Knowledge Trace，区分 Confirmed Knowledge Entry、Reference Material、Historical Expression 和模型补充背景。缺少可靠依据或存在冲突的主张必须标记为 Unverified Claim；公开内容是否展示书名、典籍或出处，由博主决定。

选题任务使用 Exploration Mode，允许模型通用背景知识帮助发现角度，但提案只作为待确认假设。Content Master 和 Platform Version 使用 Grounded Creation Mode，专业主张默认受 Creator Knowledge Base 约束，模型补充不得未经确认进入最终版本。
